# VicRoot Fabric Soil Risk

VicRoot is a Microsoft Fabric medallion pipeline for Melbourne urban soil monitoring, transforming soil/site/weather data from Bronze to Silver to Gold risk outputs.

## Map Preview

![VicRoot site risk map](docs/images/site-risk-map.png)

## Repository scope

- Fabric-ready notebooks for Bronze/Silver/Gold
- Parameter-driven runtime via `notebooks/lib/pipeline_params.py`
- Gold outputs for irrigation risk and analyst-facing map visualization
